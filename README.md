## Постоянная библиотека кода

- На карточках временного буфера есть кнопка **☆ В библиотеку**. Она шифрует фрагмент и помещает его в личную постоянную библиотеку, не удаляя исходный текст.
- Вкладка **Библиотека** содержит поиск, ручное добавление, редактирование кода и заметок, выбор языка, копирование и удаление с подтверждением.
- У каждой записи отдельный ключ `library:<username>:<id>` в том же Cloudflare KV, без TTL. Исходный код, заголовок и заметки шифруются AES-GCM с ключом аккаунта до отправки.
- Библиотека доступна только вошедшим пользователям. Записи разных аккаунтов изолированы.
- Список передаёт только идентификаторы, зашифрованные записи читаются по частям до 2 КБ с проверкой версии, чтобы избежать зависаний больших ответов.
- Изменения и удаление используют проверку версии; данные временного буфера и его срок жизни не затрагиваются.
- Эталонная ветка `stable-v2-etalon-2026-11-10` сохранена без изменений и доступна для отката.

## Принципы

- Зарегистрированные пользователи имеют отдельные зашифрованные записи сроком хранения до 7 дней.
- Гостевой режим без регистрации работает локально, записи удаляются через 5 минут.
- Сессия сохраняется при обновлении страницы до выхода или истечения срока подписи.
- Облако загружается небольшими частями, защищаясь от частично переданных ответов.
- Запись использует `baseRevision` и не должна затирать более свежие изменения с другого устройства.
- Данные шифруются на клиенте; Cloudflare хранит ciphertext, а не исходный текст.
- Единственный активный API: `https://vibejira.t-bushueff.workers.dev`.
- React-ветки в продукте не используются.
- HostiMan доступен только при ручном выборе на форме входа; по умолчанию все запросы идут напрямую на Cloudflare.

## Ручной российский прокси (HostiMan)

В форме входа есть галочка **«Вход через российский прокси»**. Без неё все запросы идут напрямую на Cloudflare. С ней **все** запросы (авторизация, буфер, библиотека, профиль, смена пароля) идут через `https://tbhelper.h1n.ru/api.php`. Автоматического переключения при ошибках нет. Выбор хранится в локальном хранилище браузера `helper-use-russian-proxy` и применяется до восстановления сессии при загрузке страницы.

Для активации прокси **вручную загрузите `hostiman/api.php` в `public_html/api.php` на tbhelper.h1n.ru**, заменив старую PHP-заглушку, и убедитесь, что доступны PHP 7.4+, расширение cURL и HTTPS. Код PHP в репозитории не разворачивается на HostiMan автоматически.

Прокси является прозрачным HTTPS-ретранслятором к прежнему Worker/KV, а не отдельной базой данных. Он пересылает токены авторизации и логины/пароли на Cloudflare; поэтому используйте только управляемый вами доверенный хостинг, защищённый HTTPS, без логирования содержимого запросов. На прокси не должны сохраняться пароли, токены и содержимое сообщений. Проверьте, что ваш веб-сервер корректно передаёт заголовок `Authorization` в PHP (`HTTP_AUTHORIZATION` либо `REDIRECT_HTTP_AUTHORIZATION`).

Для проверки API до ввода реального пароля: запрос `OPTIONS /api.php?route=%2Fauth%2Flogin` с заголовками `Origin: https://tbushueff-tech.github.io` и `Access-Control-Request-Method: POST` должен вернуть 204 и CORS-заголовки. Проверка `GET /api.php?route=%2Fauth%2Fme` без токена должна вернуть 401 JSON от Cloudflare при доступности upstream. Сначала протестируйте вход, буфер и библиотеку с тестовым аккаунтом. Если прокси недоступен, снимите галочку, чтобы вернуться к прямому маршруту.
