## Принципы

- Зарегистрированные пользователи имеют отдельные зашифрованные записи сроком хранения до 7 дней.
- Гостевой режим без регистрации работает локально, записи удаляются через 5 минут.
- Сессия сохраняется при обновлении страницы до выхода или истечения срока подписи.
- Облако загружается небольшими частями, защищаясь от частично переданных ответов.
- Запись использует `baseRevision` и не должна затирать более свежие изменения с другого устройства.
- Данные шифруются на клиенте; Cloudflare хранит ciphertext, а не исходный текст.
- Единственный активный API: `https://vibejira.t-bushueff.workers.dev`.
- HostiMan и экспериментальные React-ветки в продукте не используются.

## Проверка


Для браузерного теста необходим Playwright (см. исходный workflow релизной ветки / историю CI).

## Восстановление

Не удаляйте `main` и `stable-v2-etalon-2026-11-10`. Для восстановления эталона используйте коммит `cf28f768470e85a8d7a5b5c2bccb4a4d134c8e2d` и заново разверните код Worker, если он также изменён. Данные Cloudflare KV и секреты сохраняйте отдельно от исходного кода.
