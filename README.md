# Helper by bushueff

Личный буфер текстов: быстро сохранить, найти и скопировать фрагмент. Сайт — статическая страница на GitHub Pages, данные хранятся в Cloudflare KV в зашифрованном виде.

Адрес: https://tbushueff-tech.github.io/vibejira/

## Устройство

| Часть | Что делает |
| --- | --- |
| `index.html` | Весь интерфейс и клиентская логика. Шифрование (AES-GCM, ключ из пароля через PBKDF2) выполняется в браузере. |
| `worker/index.js` | Cloudflare Worker: регистрация, вход, подписанные сессии, хранение зашифрованного буфера в KV. |
| `hostiman/` | Необязательный PHP-прокси к Worker (см. `hostiman/README.md`). Клиентом пока не используется. |
| `worker/test/` | Автотесты Worker (`npm test`). Запускаются перед каждым деплоем. |

### Синхронизация и ревизии

Буфер пользователя — один документ KV с номером ревизии `rev`. Клиент отправляет ревизию, которую видел (`baseRevision`). Если за это время другое устройство записало данные, Worker отвечает `409` и ничего не перезаписывает; клиент загружает облако, накладывает свои несохранённые изменения (по `id` записи) и повторяет сохранение. Благодаря этому удаления синхронизируются, а изменения с двух устройств не затирают друг друга.

Записи удаляются по сроку: гость — 5 минут (только в памяти вкладки), аккаунт — 7 дней. Worker не отдаёт просроченные записи, отбрасывает их при записи и ограничивает срок жизни сверху.

## Настройка Cloudflare

Привязка KV — `USER_STORE` (см. `wrangler.toml`). Секреты Worker:

- `AUTH_SECRET` — случайная строка для подписи сессий (обязательно).

Деплой выполняет GitHub Actions при изменениях в `worker/**`. Нужны секреты репозитория `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.
