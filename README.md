## Постоянная библиотека кода

- На карточках временного буфера есть кнопка **☆ В библиотеку**. Она шифрует фрагмент и помещает его в личную постоянную библиотеку, не удаляя исходный текст.
- Вкладка **Библиотека** содержит поиск, ручное добавление, редактирование кода и заметок, выбор языка, копирование и удаление с подтверждением.
- У каждой записи отдельный ключ `library:<username>:<id>` в том же Cloudflare KV, без TTL. Исходный код, заголовок и заметки шифруются AES-GCM с ключом аккаунта до отправки.
- Библиотека доступна только вошедшим пользователям. Записи разных аккаунтов изолированы.
- Список передаёт только идентификаторы, зашифрованные записи читаются по частям до 2 КБ с проверкой версии, чтобы избежать зависаний больших ответов.
- Изменения и удаление используют проверку версии; данные временного буфера и его срок жизни не затрагиваются.
- Эталонная ветка `stable-v2-etalon-2026-11-10` сохранена без изменений и доступна для отката.

## Генератор ключей Jira

Референс: [ipwnosx/Atlassian-Agent v1.3.1](https://github.com/ipwnosx/Atlassian-Agent/tree/e34cc82dc4724b66b28c9a49ee92415b7bd19261), коммит `e34cc82dc4724b66b28c9a49ee92415b7bd19261`. Проверки выполняются относительно Java 22.0.2.

- **Ключ подписи уже совпадал с референсом.** Предыдущее описание независимо созданной пары было ошибочным. `PRIVATE_KEY_STR` в Java Encoder и `v2/demo-private-key.js` полностью совпадает с опубликованным ключом оригинального Encoder. Новая пара не создаётся. Отдельная сохранённая копия константы оригинала проверяется тестом.
- Сохранены модель свойств продуктов, `keyVersion=1600708331`, `licenseVersion=2` и точный `Description=Unlimited license by https://zhile.io`.
- Внутренний `licenseHash` подписывает UTF-8 отсортированной и экранированной сериализации TreeSet. Внешняя подпись подписывает префикс `0D 0E 0C 0A 0F` и zlib/DEFLATE. Обе подписи используют SHA1withDSA и DER. Контейнер содержит длину, payload, подпись, Base64 и `X02` с длиной Base64 в base31.
- Java HashMap(32) воспроизведён для всех наборов свойств генератора: порядок исходных вставок, hashCode строк Java, цепочки корзин, расширение таблицы и `LicenseID=null` у плагинов. Тест проверяет, что произвольный namespace в текущей схеме не может потребовать деревьев корзин; полноценная коллекция общего назначения генератору не нужна.
- Время создания Date и время для SEN/LicenseID получаются отдельными чтениями часов, как в конструкторе и init() оригинала. Для воспроизводимых сравнений программный API принимает `now`, `idNow` и `clock`.
- Программный API сохраняет пустые строки, пробелы, переводы строк, null-значения и произвольные namespace продуктов. Имя по умолчанию берётся из email только при отсутствии name; явно переданное пустое имя остаётся пустым. Форма сохраняет введённые строки и использует email, если необязательное поле имени не заполнено.
- Итоговые строки выводятся без экранирования, как в оригинале. Одиночные UTF-16 суррогаты при кодировании UTF-8 заменяются на `?` по правилам Java, включая входы обеих подписей.
- Даты используют локальную зону браузера по умолчанию. Опции `timeZone` и `locale` позволяют задать окружение сравнения явно. Таблицы переходов и последние правила SimpleTimeZone получены непосредственно из **java.util.TimeZone Java 22.0.2**, поэтому форматирование не зависит от версии tzdata браузера. Учтены исторические смещения, Julian/Gregorian cutover, летнее время, Java-имена зон, локальные цифры, Buddhist и Japanese calendars. Неизвестные ID и GMT-смещения обрабатываются как Java TimeZone.getTimeZone.
- Генерация остаётся локальной: значения формы не отправляются в Cloudflare и не сохраняются в KV. Java Agent, патчинг проверки лицензий, подмена публичных ключей и сторонний JAR отсутствуют.

`npm test` включает сохранённые результаты оригинальных Java-классов: 56 примеров свойств, 8 563 результата дат (631 зона, исторические/будущие даты и дополнительные проверки локалей и границ DST), ключ референса, контейнер оригинального Encoder и UTF-8 векторы. В property fixtures подпись заменена на `01 02 03` только для сравнения текста; реальные подписи проверяются отдельно. При генерации fixtures дополнительно проверены 128 пользовательских namespace.

`node v2/demo-java-interop.mjs` проверяет Java ↔ JS упаковку и подписи (Java 17+). Подписи DSA случайны даже между двумя запусками самого оригинала; корректные DEFLATE-потоки разных версий zlib также могут различаться. Поэтому сравниваются свойства, подписываемые байты, структура контейнера, распаковка и криптографическая проверка, а не равенство готовых ключей между запусками.

Для повторного получения таблиц зон на Java 22.0.2:

```bash
java --add-opens java.base/sun.util.calendar=ALL-UNNAMED --add-opens java.base/java.util=ALL-UNNAMED v2/java/ExportJavaZones.java v2/java-time-zones.js
```

Ветки `main` и `stable-v2-etalon-2026-11-10` сохраняются; эталонная ветка не изменяется.

## Принципы

- Зарегистрированные пользователи имеют отдельные зашифрованные записи сроком хранения до 7 дней.
- Гостевой режим без регистрации работает локально, записи удаляются через 5 минут.
- Сессия сохраняется при обновлении страницы до выхода или истечения срока подписи.
- Облако загружается небольшими частями, защищаясь от частично переданных ответов.
- Запись использует `baseRevision` и не должна затирать более свежие изменения с другого устройства.
- Данные шифруются на клиенте; Cloudflare хранит ciphertext, а не исходный текст.
- Единственный активный API: `https://vibejira.t-bushueff.workers.dev`.
- HostiMan и экспериментальные React-ветки в продукте не используются.
